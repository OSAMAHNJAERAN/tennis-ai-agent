## Reproduce without overwriting evidence

Use an existing prepared model-free API environment, the frozen frontend build and the primary Python Playwright installation. TestClient/browser/server commands need the local-socket execution permission. From the repository root, choose a new sibling fixture directory (mkdir must fail if it already exists):

```bash
TENNIS_BROWSER_CASE=artifacts/validation/yolo26_execution_2026-10-22/owner_browser_reproduction_v1
mkdir "$TENNIS_BROWSER_CASE"
cp artifacts/validation/yolo26_execution_2026-10-22/owner_browser_cloud_v3/generate.py "$TENNIS_BROWSER_CASE/"
cp artifacts/validation/yolo26_execution_2026-10-22/owner_browser_cloud_v3/serve.py "$TENNIS_BROWSER_CASE/"
/workspace/.venv-tennis-api/bin/python -B "$TENNIS_BROWSER_CASE/generate.py"
/workspace/.venv-tennis-api/bin/python -u -B "$TENNIS_BROWSER_CASE/serve.py"
```

Run the browser in a separate task-owned command while that server runs:

```bash
python3 artifacts/validation/yolo26_execution_2026-10-22/owner_browser_cloud_v1/run_browser.py --fixture "$TENNIS_BROWSER_CASE" --output "$TENNIS_BROWSER_CASE/browser_run1"
```

Stop gracefully by creating only that case's stop-request file and wait for process exit; then inspect server_stopped.json, forbidden import counters, worker_failure.txt absence and the source hashes. Never dispatch original uploaded jobs or substitute actual admission probes/models for these deliberately synthetic values. A failed run that has already published a correction requires a fresh fixture for a new complete journey.
