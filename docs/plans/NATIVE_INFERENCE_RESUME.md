# Native within-inference recovery

22 October 2026. The completed-player-prefix/raw-ball continuation is implemented in the selected native YOLO26 pipeline and worker. Its executed proof uses real codecs, software and worker processes over eight synthetic frames, with explicitly injected model results and asset admission. It does not qualify actual selected-model recovery, real matches, speed accuracy, long-duration capacity or live operation. Production model qualification checks remain in place.

The reusable boundary is after the entire player/court/identity pass and whole-video player-role selection, during the subsequent stateless ball pass. Arbitrary interrupted BoT-SORT/GMC/Kalman state is not restored. Process loss before a complete player prefix remains ineligible for automatic continuation; an owner retry creates a new analysis from the retained original.

## Retained state

`src/utils/native_inference_session.py` seals normalized `source.mp4`, `media_metadata.json` and `inference_config.yaml`, plus the presence and exact bytes of optional `source_frame_mapping.jsonl` and `normalization_frame_stats.txt`. `.native_inference_source.json` binds the existing original/config/model/runtime/source identity. Generated assets are hashed in bounded chunks and are not retranscoded during eligible recovery. The detached derived identity is limited to 64 KiB; source/prefix markers to 128 KiB; scalar media-metadata parsing to 1 MiB. Redirected paths, symlinks, junctions, reparse points, malformed JSON and changed optional presence fail verification.

After whole-video role selection, person export and the tracking-to-crop transition, `src/utils/native_inference_prefix.py` writes `.native_inference_prefix.sqlite3` and exclusively publishes `.native_inference_prefix.json`. It preserves typed initial calibration and fourteen landmarks, both selected role sequences and exact source proposal indices, per-frame registrations, candidate source/interval/identity/court observations, and the four closed camera/interval/identity/people audits. Numerical buffers and scalar types survive; sanitized public JSON is not used to reconstruct raw observations. Reopened bounded views detach their current row and verify signatures/hashes. A private partial database without its seal is ineligible.

`src/utils/ball_inference_journal.py` owns `.ball_inference.sqlite3`. For each global frame, the actual ball adapter finishes full-frame inference and every configured tile before one SQLite FULL-synchronous DELETE-journal transaction inserts its immutable raw candidates and advances `next_frame`. Empty candidate frames commit once. Index gaps, malformed/oversized records, unexpected schema objects, active schema changes and mismatched identity/device/configuration fail. Failed transactions poison the owner; only reopening resolves ambiguous commit acknowledgement. Recovery may open the journal read/write for SQLite hot-journal rollback, but validation never adds candidate frames.

Raw ball identity binds the exact completed-prefix seal bytes, normalized/source identity, ball policy and explicit `cpu` or indexed `cuda:N`. A saved automatic selection becomes its explicit resolved device on recovery. The crop provider must reproduce its recorded checkpoint preprocessing and clean prediction policy; ball placement must match that device. No fourth vision model is constructed.

Seals use exclusive hardlink publication and retain staging links for diagnostics. Existing seals and sealed prefix files are not overwritten or deleted, and accepted raw rows remain immutable while the journal appends its suffix. Derived scratch, exports and rendering are deliberately rebuilt. Windows hard process termination was tested; power-loss durability is not established.

## Pipeline continuation

`src/pipeline/phase6_pipeline.py` accepts the derived `inference_identity` only for the selected native ball path. With a valid prefix it skips initial court prediction and the complete player/court/identity pass, restores selected role/source observations, cleans the fresh selected player model for crop-only use and checks the same crop policy/device. Event authority remains withheld under dynamic court registration in both fresh and restored paths.

`VideoFrameSequence.iter_decoded(next_frame)` opens a fresh decoder, sequentially decodes/discards preceding normalized frames and yields only the suffix to ball inference. No discarded frame is forwarded and no approximate seeking is used. This uses sequential decoder ordering on normalized media, with pixel equivalence tested on the synthetic fixtures; original variable-rate PTS and slow-motion qualification remain separate.

After the raw frontier reaches the full normalized count, all raw rows are copied to new mutable scratch storage. Stationary/neighborhood/motion filters, temporal association, events, rules, analytics, rendering and exports rerun globally. Filtered rows never overwrite retained raw candidates or concatenate independently interpreted chunks. Crop failures remain latched even if a legacy consumer catches the first error, and fail publication. Metrics/return values record prefix reuse and raw reused/inferred/total counts.

## Worker and publication

`src/api/worker.py` admits partial recovery only when both model family and ball backend are `yolo26`. The strict `.pipeline_checkpoint.json` completed-stage marker takes precedence and retains its original loader contract. If no completed marker exists, startup validates the separate source/prefix/raw-frontier contract under the exclusive worker lock before the same PROCESSING analysis can be requeued. Corrupt completed state never falls back to an older prefix.

`process_job` reuses sealed normalized assets on valid partial continuation, passes the derived identity into the actual pipeline and checks the source again before writing the completed-stage seal. Final generation publication repeats that source-seal check after copies and immediately before commit. Independent review found and closed a window between the post-pipeline source check and completed-marker hashing. Older completed-only jobs without a native source seal retain their previous contract.

Owner/cancellation checks, the same analysis ID, ordinary failed-model behavior and the existing three-attempt ceiling remain. No private partial prefix or journal becomes a completed result. Fresh continuation still needs the existing model asset/qualification admission; these software changes do not promote pilot weights.
