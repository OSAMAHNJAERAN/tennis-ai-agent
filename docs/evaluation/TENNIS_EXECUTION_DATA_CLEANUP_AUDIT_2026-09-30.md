The execution gate remains **at least twelve untouched clips from at least six actual independent matches or recording sessions**, grouped before model selection. Reserve two clips per new session, identify their common source, and exclude every adjacent rally, resized duplicate, and shared broadcast from training/validation. Obtain authorized elevated baseline singles footage with court visibility and diversity in surface, lighting, far-player scale, compression, and modest camera behavior. Publisher test lists can be acquisition leads only after source grouping, rights, overlap, and model-training exposure are assessed; they were not downloaded here.

Each reserved clip needs a frozen input hash, source URL/version/license/release, source-session identity, decoded resolution/FPS/PTS, split assignment, independent ball/player/pose/racket/court visibility labels, camera segments, negative intervals, label-review record, and immutable acceptance criteria. Annotators must not see the selected model's predictions while making final labels. Freeze thresholds/tolerance before inference, run qualification once, report clip/group results and session-level confidence intervals, and acquire new final data after tuning on any failure. Independent measured speed/3D references are absent from the reviewed set and remain a separate unmet gate.

## Timestamp mapping is an explicit measurement gap

[The worker](../../src/api/worker.py) probes average/nominal rate and time base, applies an FFmpeg constant-rate filter, and states `EXACT_SOURCE_FRAME_MAPPING_NOT_RECORDED` with `frameMapping: null`. Counting equal normalized/annotated frames proves internal normalized alignment; it does not prove exact original-frame identity or original acquisition timing for dropped/duplicated/VFR frames. A verified source PTS → normalized frame mapping, source start offset, and duplicate/drop policy are required before precise timing/physical-speed claims.

There is a concrete provenance inconsistency: the current primary 2024 Commons original is **29.937 seconds**, while [the local diagnostic manifest](../../data/benchmarks/cross_match_final_holdout/videos.json) records **1,795 frames / 30 FPS = 59.83 seconds** for the matching local file hash. This may reflect an old conversion or source revision, but its cause is unestablished. Do not silently assign official match timing/speeds to the local derivative. Recover the actual conversion/revision and compare source/local PTS, frame sequence and playback duration before using that clip as timing evidence. Likewise, the 2012 original file lengths and shorter local excerpts need explicit trim offsets.

## Accuracy work justified by existing failures

- **Ball:** [Tiled proposal development results](../experiments/BALL_TILED_PROPOSALS.md) report 93.67% precision / 95.40% recall on the twelve-clip expansion; difficult `match148` gives 77.50% / 81.58%. [The later spaced error audit](../experiments/BALL_SPACED_ERROR_AUDIT_RESULTS.md) attributes 19 of 26 visible misses to absent correct proposals and records 29 absent-frame false detections. Prioritize proposal coverage, native-scale context, and reviewed negative labels; a ranking-only change cannot recover missing proposals. These are different reused configurations/data, not final accuracy for the API default.
- **Players/court:** [UVY baseline](../experiments/UVY_PLAYER_TRACKING_BASELINE.md) records zero selected players on three side-camera clips despite many person proposals, with court landmarks imposed onto spectators. Improve geometry rejection and independent active-player evidence; do not lower fit thresholds or equate low residual with true image alignment. UVY labels themselves omit players/mislabel an umpire.
- **Rackets:** [Existing temporal crop evidence](../experiments/COCO_RACKET_COMPARISON.md) gives 77.38% precision / 63.73% recall on 92 reused positive frames, with no absence/ownership qualification. [Tracker/racket comparison](../experiments/TRACKER_RACKET_SELECTION.md) finds a spectator selected by false head/hand detections. Ownership, full-racket crops, actual negatives, and temporal association need independent labels before a specialist is promoted.
- **Court improvement:** [Frozen refinement results](../experiments/COURT_REFINEMENT_SELECTION_RESULTS.md) improve development landmark agreement but lose boundary matches when relevant lines are absent. Retain these rejection cases; validate against independent image landmarks and grounded references, not support score alone.
