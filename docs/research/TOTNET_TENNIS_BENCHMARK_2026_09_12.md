# TOTNet tennis: source and runtime review

Official repository revision: `8a757f63391b262c14d18b4095486336852dbeef`. Research source archive: `artifacts/research/TOTNet/source`; individual file SHA-256 values in `source_manifest.json`. The archived LICENSE is MIT. [Official repository](https://github.com/AugustRushG/TOTNet/tree/8a757f63391b262c14d18b4095486336852dbeef).

The public tennis best checkpoint is 94,145,122 bytes, Git blob SHA-1 `96b3b5ba60a5a2d2b3f2d9b538999c3c3a76a560`, SHA-256 `36caadd2453cf1a37f26afb0024b861fd3285ca6e9a91e9e4a20d35e90a0a24a`. The download matches the tree's Git blob identity and every ZIP member passes CRC. `artifacts/models/ball/totnet_research/inspection.json` records its exact source URL. No paper-reported performance is used as local qualification evidence.

The checkpoint contains training configuration and optimizer data as well as model tensors. Static pickle globals consist of standard Torch storage/rebuild/device records, OrderedDict, and EasyDict. An initial restricted load with the genuine EasyDict class failed because Torch 2.13 prohibits SETITEMS on that subclass. The successful extraction uses standard `torch.load(weights_only=True)` with the metadata class name mapped to built-in OrderedDict, which avoids running EasyDict methods. No custom unpickler, unrestricted pickle, generic getattr, HistoryBuffer, or NumPy reconstruction is used. Configuration is treated as inert mapping data. Only model tensors are exported; no optimizer or configuration objects are included.

The exported plain tensor checkpoint SHA-256 is `66395b83760d533e8c9a43eb3b5a00e7b24a018d74f6d9232489dae6224dd7a2`. All 196 tensors match exactly on a fresh default restricted reload. The author architecture accepts all keys with `strict=True`, yielding 8,654,467 parameters. Saved configuration confirms epoch 25, model TOTNet, tennis dataset, 64 channels, five frames, input height 288/width 512, `bidirect=False`, WBCE, visibility weights `[1,2,3,3]`. The filename's 30 epochs describes the training run, not the selected checkpoint's epoch.

Import the direct [TemporalConvNet module](https://github.com/AugustRushG/TOTNet/blob/8a757f63391b262c14d18b4095486336852dbeef/src/model/TOTNet.py), whose runtime imports are Torch and einops. The model registry imports unrelated model packages. The official [pretrained helper](https://github.com/AugustRushG/TOTNet/blob/8a757f63391b262c14d18b4095486336852dbeef/src/model/model_utils.py) filters state keys and fills missing values from the newly initialized model; our benchmark deliberately requires an exact match instead.

Input is `[B,5,3,288,512]`, chronological, with the last frame as target. Unlike WASB's three sigmoid heatmaps, TOTNet returns one flattened `[B,147456]` spatial softmax. Decode via spatial argmax; peak probability is not a calibrated ball-presence confidence. The network module has historical implementation quirks (some repeated temporal layers use the same input); preserve the author's actual forward computation for checkpoint fidelity rather than repairing it during evaluation.

The official [tennis dataset](https://github.com/AugustRushG/TOTNet/blob/8a757f63391b262c14d18b4095486336852dbeef/src/data_process/dataset.py) keeps OpenCV BGR. Its [test transform](https://github.com/AugustRushG/TOTNet/blob/8a757f63391b262c14d18b4095486336852dbeef/src/data_process/transformation.py) stretches with Lanczos4 to 512 by 288, divides by 255 and applies ImageNet mean/std. There is no BGR-to-RGB conversion. The benchmark verifies exact float32 pixel equality with those archived transform classes before inference. Original dataset code substitutes black images when a requested file is missing; our pilot uses five real consecutive frames and separately counts boundary abstentions, without fabricating missing frames.

Dependencies are isolated under `artifacts/research/TOTNet/vendor`: einops 0.8.1 wheel SHA-256 `919387eb55330f5757c6bea9165c5ff5cfe63a642682ea788a6d472576d81737`, EasyDict 1.13 wheel SHA-256 `6b787daf4dcaf6377b4ad9403a5cee5a86adbc0ca9a5bcf5410e9902002aeac2`. EasyDict was inspected and installed for the unsuccessful initial load; successful export and inference do not import it. System packages were not changed.

The frozen local pilot is specified in `docs/experiments/TOTNET_BALL_PILOT.md`. Training-source overlap and broad camera generalization remain unverified. A successful tensor extraction establishes runtime compatibility only; it does not establish accuracy or production readiness.
