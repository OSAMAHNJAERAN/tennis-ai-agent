## Physical-reference exclusion

[Where Is The Ball, arXiv `2506.05763v1`](https://arxiv.org/html/2506.05763v1) explicitly says its real tennis data lack 3D ground truth; the measured mocap data use a 40 mm ping-pong ball with eight IR cameras at 50 Hz. Its tennis qualitative example uses thirteen clips from one match. These are not measured tennis-ball references. The [author project](https://where-is-the-ball.github.io/) still labels code, simulation and dataset as forthcoming. GitHub API verification pinned website revision `00e06706deb084e635c0c93f9c7d9085ac3f3843`; `index.html` blob `ae399c27a7803f9d325ea548056984b22f6e521c`, 27,556 bytes, contains those labels. The paper's CC BY license does not independently license an unreleased dataset or underlying broadcasts.
