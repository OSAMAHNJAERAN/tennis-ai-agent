# WASB head-only adaptation on sixty training clips

Frozen 2026-09-14 before training. Previous spatial adaptation improved internal focal loss but failed external precision and internal detection-based threshold comparison. Test a conservative transfer candidate: retain all original HRNet features and update only `final_layers.*` for one epoch over the verified 48 training clips (2,399 sparse labels). The original official checkpoint is the initialization and comparison. No model downloads or paid compute.

Use the existing spatial-view preparation and augmentation unchanged: full frame plus four 60% crops, one uniformly sampled view per source label per epoch, random supervised output slot, real adjacent context, flip, brightness/contrast and motion blur. A single explicit target supervises only its output frame. Retain the original sparse labels, including publisher absence and the recorded contact ambiguity; no assistant labels or external outcomes enter training. This pilot does not resolve label uncertainty. Temporal context remains adjacent during training; deployment selection uses FPS-adjusted spacing. That mismatch remains explicit and may warrant a later controlled ablation.

Freeze all non-head parameters and all batch-normalization state with model.eval(). Use seed 7, batch 1, one pass without replacement, AdamW learning rate 0.00001, weight decay 0.0001, AMP, gradient clipping 1. Preserve original/checkpoint hashes. Run a three-update smoke on a training example, require finite loss and nonzero head gradients, and verify every frozen tensor unchanged; restore original model state and reset optimizer/scaler/random seeds before the actual epoch. Save original and trained head diagnostics. This changes data quantity, parameter scope and epoch count relative to earlier pilots, so it is not a single-variable causal ablation.

Evaluate the original and completed one-epoch checkpoint using all 600 labels from twelve reserved publisher training clips, five views, real target-aligned temporal windows with native-FPS spacing, unchanged cross-view confidence ordering and the predeclared thresholds .10/.20/.35/.50/.70. Decode each threshold from averaged heatmaps independently. Choose each model's threshold by pooled frame F1, then precision, recall, proximity to .20 and lower threshold, exactly as the previous threshold-selection protocol. Do not select a different epoch: there is only one.

For the original model, reuse the prior verified predictions for the first eight reserved clips (400 labels) only after checking its complete report, model/code/source hashes and every source target/window. Infer the four new reserved clips (200 labels) with the same function. The trained model must infer all twelve clips. Preserve every candidate and selected point at all thresholds, per-clip results and completion state. On each newly inferred clip/model, compare the first label's .20 path to existing inference. Independent scoring must reproduce the selected thresholds and pooled/per-clip results.

If the adapted model has strictly higher selected pooled F1 than the original, freeze the two model/threshold pairs for a later complete eighteen-clip external raw comparison. Report recall losses and subgroup regressions even if this internal gate passes. If it does not win, retain rejection and do not spend on external inference for this candidate. Neither outcome authorizes a runtime replacement; continuous filtering, video review and independent qualification remain required. Source-broadcast independence, absence-label quality and original checkpoint exposure remain unverified.

Expected cost: several minutes for one training epoch plus approximately ten minutes for preparation and sparse internal inference, using the existing RTX 4050. Persist completed preparation, checkpoint and clip results and stop on provenance mismatch, nonfinite loss or unexpected frozen-state mutation. Do not restart a live job. Completed outputs remain protected from overwrite.
