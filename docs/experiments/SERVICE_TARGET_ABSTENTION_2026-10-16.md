`TennisLineCallEngine.evaluate_bounce` now returns `REVIEW_REQUIRED` for an absent or invalid service target before reading a trajectory, accessing frames, refining contact or projecting a position. It does not substitute another service box. The abstention has reason code `SERVICE_TARGET_UNAVAILABLE`, confidence zero and null positions, signed distance, edge margin, contact radius and spatial uncertainty. Its refinement is explicitly `NOT_PERFORMED`; an invented metric origin or zero margin cannot appear as evidence. Canonical enum targets and canonical value strings use the existing geometric path. Rally calls retain their existing target-independent path.

The caller may use `LineCallEvidence.unavailable(event_id, bounce_frame, context, reason, reason_code)` to record a missing current identity/end/calibration prerequisite before invoking the geometric engine. This helper does not establish the caller's authority or validate an identity binding. The native scoring/point timeline handoff now uses it; current player-role IDs alone do not establish stable participant identity or a service target.
